# AURELIS — Kinetic Architectural Lighting

An experimental premium landing page concept for AURELIS, a fictional architectural lighting studio exploring the relationship between light, architecture, technology and atmosphere.

## Overview

AURELIS presents architectural lighting as both a technical discipline and a creative medium.

The website uses an editorial and immersive visual direction with large typography, dark cinematic backgrounds, interactive 3D elements and highly minimal layouts.

## Features

- Immersive full-screen hero
- Interactive 3D lighting visualization
- WebGL background
- Three.js integration
- Kinetic scrolling imagery
- Editorial typography
- Technical specification sections
- Project showcase
- Global presence section
- Interactive hover states
- Scroll-triggered animations
- Responsive navigation
- Mobile-responsive layout

## Design

The visual identity is built around:

Link to the Landing Page:

## Experience

The website uses large-scale typography, sparse layouts, kinetic movement and interactive 3D elements to create an immersive architectural experience.

The hero introduces the concept through the statement:

"FORM THROUGH LIGHT"

The experience then moves through the studio's manifesto, technical laboratory, selected works and global presence.
